DATABASE BACKUPS

数据库备份管理

GitHub Actions 每天日本时间 03:05 自动导出 D1，在 GitHub 临时 Runner 中使用 AES-256-GCM 分块加密并上传到独立私有 R2。只有所有者可以查看、验证、下载或删除备份。D1 导出期间可能短暂无法处理查询，请勿在高峰时段手动触发。

下载的是加密文件，不是明文 SQL。完整恢复仍须在独立测试 D1 中执行，并先处理快照时间点之后的账号删除台账；当前面板不会提供覆盖生产库的一键恢复。
